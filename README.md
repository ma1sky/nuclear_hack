# Некиро-стенографист — HEX-TEAM

## Состояние проекта

Объединены интерфейс, WAV/M4A/AAC-подготовка, диаризация sherpa-onnx, GigaAM ASR, локальное резюме Qwen и строгий JSON/TXT-экспорт. Ошибки не заменяются тестовыми результатами. Нативный аудиокод скомпилирован против реального AAR; release APK и инференс на Redmi пока не подтверждены: Gradle-сборка остановилась на TLS при загрузке Maven-зависимостей. Инструкции для Android Studio, сборки APK и контрольного прогона собраны в [документации приложения](app/README.md).

Команда: 4 человека. Официальное окно: 21 час. Стопкодинг: **7 ноября 2026 года, 21:00 МСК**. Точное начало окна и правила предварительной разработки необходимо подтвердить у организаторов.

Основной маршрут: **React Native + TypeScript + Expo development build → локальный Expo Module на Kotlin → sherpa-onnx**.

Подготовка проверочного APK: [встроенный комплект моделей](docs/model-bundle.md). Сборка требует все пять файлов; первый запуск не требует скачивания.
