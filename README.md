## Состояние проекта

Объединены интерфейс, WAV/M4A/AAC-подготовка, диаризация sherpa-onnx, GigaAM ASR, локальное резюме Qwen и строгий JSON/TXT-экспорт. Ошибки не заменяются тестовыми результатами. Release APK собран для ARM64 и x86_64; на Android-эмуляторе подтверждены первый запуск, подготовка встроенных моделей, WAV-импорт, ASR/диаризация, история, строгий JSON и локальная LLM в авиарежиме. В резюме отмечены смысловые ошибки. M4A и независимые WER/DER-замеры описаны в [расширенном отчёте](docs/podcast-benchmark-2026-11-07.md): выявлены лишние speaker ID и ошибки резюме. Качество подкастов и работа на Redmi ещё не подтверждены. [Отчёт Android](docs/android-smoke-2026-11-07.md). Инструкции для Android Studio, сборки APK и контрольного прогона собраны в [документации приложения](app/README.md).

Команда: 4 человека. Официальное окно: 21 час. Стопкодинг: **7 ноября 2026 года, 21:00 МСК**. Точное начало окна и правила предварительной разработки необходимо подтвердить у организаторов.

Основной маршрут: **React Native + TypeScript + Expo development build → локальный Expo Module на Kotlin → sherpa-onnx**.

Подготовка проверочного APK: [встроенный комплект моделей](docs/model-bundle.md). Сборка требует все пять файлов; первый запуск не требует скачивания.
