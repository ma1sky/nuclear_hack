# Некиро-стенографист — HEX-TEAM

Android-приложение для локальной расшифровки разговоров с автоматическим разделением говорящих и временными метками реплик.

- [Технологический стек](docs/stack.md) — архитектура, модели, инструменты и порядок проверки интеграции.

## Состояние проекта

Подготовлен первоначальный план. Код приложения, зависимости и модели пока не добавлены. Выбранный стек требует проверки на реальном Android-устройстве.

Команда: 4 человека. Официальное окно: 21 час. Стопкодинг: **7 ноября 2026 года, 21:00 МСК**. Точное начало окна и правила предварительной разработки необходимо подтвердить у организаторов.

Основной маршрут: **React Native + TypeScript + Expo development build → локальный Expo Module на Kotlin → sherpa-onnx**.
