# Русский WAV для первого прогона

`gigaam-example.wav` — реальный аудиопример из официального архива GigaAM для sherpa-onnx. Источник, имя архива и SHA-256 записаны в SOURCE.json. Этот файл поставляется вместе с моделью и не считается независимым тестом качества.

Фактический результат Android-прогона: `../test-results/android-smoke-transcript.json`. Для независимой оценки использовать `../../docs/test-datasets.md`.
