# Исправление OOM длинного аудио — 8 ноября 2026

## Причина

v1.2 создавала полный FloatArray mono 16 kHz: для часа 230 400 016 байт.
Лимит Java-кучи Android-процесса — 201 326 592 байта. AAC дополнительно
накапливал полный PCM в ByteArrayOutputStream; ресемплинг и нормализация
создавали дополнительные копии.

## Изменения

- Runtime-подготовка WAV и AAC записывает mono float PCM в приватный cacheDir.
  Полные записи не переводятся в Java-массив.
- RIFF-проверки, PCM16 mono/stereo и дополнительные WAV-чанки сохранены.
- AAC декодируется MediaCodec порциями прямо в файл; полного ByteArrayOutputStream нет.
- Ресемплинг выполняется секундными ядрами с соседним контекстом и глобальной
  временной шкалой. Фильтр прежний; дрейфа из-за независимого округления AAC-пакетов нет.
- Нормализация использует ограниченное количество проб по всей записи и один общий
  коэффициент усиления, а не разный gain на каждом окне.
- Огибающая вычисляется последовательными секундными блоками.
- Диаризация: до 120 секунд прежний алгоритм; длинные файлы обрабатываются
  неперекрывающимися окнами максимум 120 секунд. Максимум одного входного
  FloatArray — 7 680 000 байт, не считая ограниченных IO-буферов.
- Между окнами голоса сопоставляются по embeddings самых длинных реплик
  и глобальным центроидам. Разные локальные кластеры в одном окне не получают
  один и тот же глобальный ID. Порог cosine 0.65 новый, ещё требует калибровки DER.
- ASR читает интервалы из файла блоками до 20 секунд, сохраняет исходные метки.
- Файлы закрываются и удаляются через use/finally после успеха, ошибки и отмены.
  Ресурсы MediaCodec, MediaExtractor и sherpa освобождаются независимо.
  Отмена ожидает завершения текущего нативного окна.

UI и экспортная схема не изменены. Лимит кучи не увеличен.
Файловый PCM требует свободного места: около 230,4 МБ для часа mono 16 kHz,
плюс исходное аудио; при ресемплинге временно существуют два PCM-файла.
Аварийное завершение процесса ОС может оставлять cache-файл: отдельная очистка
после принудительного завершения пока не реализована.

## Проверки

- 11 прежних Kotlin-проверок аудиопайплайна и проверки хранилища моделей прошли.
- Новые JVM-проверки с -Xmx64m: подготовка часового WAV и чтение ASR-интервала
  в конце записи; совпадение ресемплинга 44,1 kHz с прежним фильтром, в том числе
  на границах секунд; удаление PCM при отмене. Все три прошли.
- TypeScript, ESLint и Android assembleRelease прошли.
- APK установлен без удаления данных в Release12, Android 17, x86_64, 4 ГБ RAM.
- Настоящий размеченный часовой AMI IN1016 прошёл подготовку и дошёл до диаризации.
  Прежний OOM не повторился. Подготовка наблюдалась через 16,74 с внешнего сценария.
  Во время диаризации одна выборка dumpsys: Java Heap 14 504 КБ,
  TOTAL PSS 404 773 КБ. Это выборка, не измеренный точный пик.
- Запрошена и подтверждена кооперативная отмена, приложение принимает следующую задачу.
- После отмены короткие WAV и stereo AAC 44,1 kHz успешно прошли ASR, локальное
  резюме и строгий JSON. Текст обоих: «шестьдесят тысяч тенге сколько будет стоить».
  Это совпадение короткого эталона, не оценка качества подкастов.

Результаты: artifacts/test-results/hour-ami-2026-11-08/oom-fix/result.json,
artifacts/test-results/oom-fix-2026-11-08/{wav,aac}/results.json.
Дополнительный полный тест 150 секунд AMI прошёл: два окна диаризации,
ASR, локальное резюме, строгий JSON и возврат из предпросмотра к экспорту.
Внешнее время с UI-наблюдением — 106,23 с.
Результат: artifacts/test-results/oom-fix-2026-11-08/two-windows/results.json.
Это английская речь, а ASR русский: результат содержит русскую транслитерацию
английского и не является успешным тестом качества английского распознавания.
DER на этом фрагменте не вычислялся. Тест подтверждает работу двухоконного пути,
а не корректность назначения каждой реплики участнику.

Полный часовой прогон впоследствии завершён: 34 мин 45 с, без OOM.
Качество неудовлетворительно: 73 ID вместо четырёх, DER итогового JSON 71,62%.
Подробности: [полный часовой тест](hour-audio-full-test-2026-11-08.md).
Особенно требуют проверки границы окон, короткие реплики и соответствие голосов.
Redmi Note 11S не подключён; измерения относятся к эмулятору.
