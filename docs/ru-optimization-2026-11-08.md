# Пункты 1/3: модели, ранний текст и сопоставление

8 ноября 2026. Фаза до смены extractor: Eres2Net. База APK b5fb30861cf866ed39f990527a3400453c23cf405d2849a656b1c6bec0190fca; кандидат 99180b3c5dcfc335d8041f14e5938d918bf92e00314d7709fefa6be55459392d.

Диаризатор и дополнительный extractor создаются один раз на запись и переиспользуются в окнах 120 с. Ресурсы освобождаются до ASR. Сопоставление участников между окнами выполняется совместно с взаимно-однозначным назначением; отсутствующие и короткие признаки не создают фиктивные центры: используется speaker_unknown. Реплики и миллисекунды сохраняют исходное смещение. Известные ID нумеруются по первому появлению распознанной речи.

Расшифровка сохраняется до Qwen, сразу открываются текст и экспорт. JSON трёхминутного подкаста открыт во время LLM и после резюме остался идентичен. В этой фазе обнаружен повторный переход на результат после LLM; однократная навигация только с активного экрана и ясное состояние отмены включены в следующую сборку.

В трёхголосном тесте DER экспорта снизился 30.67% → 27.84%; известные ID: 7 → 5 плюс 2 неопределённые реплики общей длиной 2.227 с. Эталон содержит три голоса, лишние локальные кластеры остаются. При исключении неопределённых реплик из известных DER тот же. Новых известных ID после первого окна здесь нет.

Само переиспользование сессий заметного ускорения полного цикла не дало: трёхголосный тест целиком 191.62 с против 176.23 с. Текст появился за 98.05 с вместо 175.5 с. Пятиминутный подкаст: текст 157.45 с, полный сценарий 339.11 с. Более быстрый extractor исследован в [следующей серии](runtime-options-2026-11-08.md).

Все шесть файлов завершились с локальным резюме и корректным JSON без OOM. У базы пять сопоставимых файлов; пятиминутного подкаста в ней нет. Три размеченных теста — синтетические 60-секундные русские смеси, повторённые трижды с сохранением ID. Подкасты без ручного эталона: WER/DER не заявляется. Golos: WER 0 только на одном эталоне из шести слов.

Замеры: Android 17 x86_64, 6 vCPU, 4 ГБ, авиарежим. Redmi не проверен. Время включает опрос UI, память — максимум выборок PSS. Полные времена одноголосного и двухголосного кандидата исключены из сравнения: обнаружение завершения задержалось из-за вкладки. Диагностические/прерванные прогоны сохранены отдельно. Повторы одним процессом не доказывают отсутствие утечек.
