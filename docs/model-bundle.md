# Проверочная сборка со встроенными моделями

Основание: [Q&A 6 ноября, ответ 20:45](qa-clarifications-2026-11-06.md). Для нашей проверочной сборки все стадии доступны без скачивания, включая первый запуск после чистой установки.

## Сборка

В `app/models/` разместить реальные файлы с фиксированными именами:

| Имя | Содержимое |
|---|---|
| `gigaam-v2.int8.onnx` | GigaAM v2 CTC `model.int8.onnx` |
| `gigaam-tokens.txt` | Его `tokens.txt` |
| `pyannote-segmentation.int8.onnx` | Segmentation 3.0 `model.int8.onnx` |
| `3dspeaker.onnx` | `3dspeaker_speech_eres2net_base_sv_zh-cn_3dspeaker_16k.onnx` |
| `qwen2.5-0.5b-instruct-q4_k_m.gguf` | Qwen2.5-0.5B-Instruct Q4_K_M |

Источники версий и лицензии указаны в [плане](implementation-plan.md). Скрипт не скачивает и не заменяет отсутствующие файлы. Веса остаются вне Git. Проверка SHA-256 здесь обнаруживает повреждение при упаковке/копировании; подлинность исходного скачанного файла нужно отдельно проверить по источнику перед упаковкой.

Из `app/`: `npm run models:pack`. Скрипт проверяет наличие всех пяти непустых файлов, помещает их в Android assets локального модуля и записывает manifest с длинами и SHA-256. Config plugin вызывает тот же шаг при Android prebuild. `npm run android` также выполняет упаковку перед запуском сборки, в том числе при уже созданной Android-папке.

Gradle-модуль проверяет существование и целостность assets до компиляции: обход npm/prebuild не позволяет собрать APK с неполным комплектом. Файл manifest генерируется после успешного копирования всего комплекта.

## На телефоне

`AudioEngine.prepareModels()` проверяет manifest и копирует assets в приватный каталог. Возвращает пути по ключам `asr`, `tokens`, `segmentation`, `embedding`, `llm`. Повторный вызов переиспользует файлы только после проверки хеша; повреждённый файл восстанавливается из APK. Запись через временный файл предотвращает использование оборванной копии.

Кнопка подготовки моделей не требует сети. Готовность весов не означает готовность инференса: текущие capabilities ASR/диаризации/LLM остаются false, пока адаптеры не реализованы.

## Приёмка

1. Чистая установка проверочного APK, сеть отключена до первого запуска.
2. Подготовка всех моделей; отсутствующие assets, неверная сумма и нехватка места дают ошибку, без попытки загрузки из интернета.
3. Новая русская запись → реальное распознавание, диаризация, отдельное резюме и JSON.
4. В комплекте сдачи явно обозначена проверочная сборка со встроенными моделями.

Пункты 1–3 требуют отдельной проверки APK на устройстве. Unit-тесты упаковки используют только маленькие фикстуры во временной папке и не являются моделями для приложения. Поддержка английского пока не заявляется. Разрешение INTERNET не удаляется на основании неоднозначной реплики участника; runtime подготовки моделей сеть не использует.
