# Установка и использование

Сборка: **1.2.3**, versionCode **12**, package `team.hex.nuclearstenographer`. APK содержит ARM64 и x86_64, JS и все модели; Metro и компьютер для работы не нужны. Минимальная версия по манифесту — Android 7.0 / API 24; совместимость всех устройств с этой версией не проверена. Проверен x86_64-эмулятор Android 17 с 4 ГБ RAM. Redmi Note 11S не проверен.

## Установка

1. Скачайте APK и SHA256SUMS.txt по ссылкам в корневом README. Репозиторий закрытый: для скачивания нужен доступ GitHub.
2. Освободите несколько ГБ внутренней памяти: кроме APK около 911 МБ нужны установленное приложение, локальные копии моделей, аудио и временный PCM. Точный минимальный запас не измерен.
3. Откройте APK на телефоне, разрешите установку из выбранного источника и установите приложение. Первый запуск копирует и проверяет встроенные модели, интернет не требуется.
4. Для обновления должна совпадать подпись. Сборка подписана тестовым ключом. Перед удалением другой сборки экспортируйте нужные данные.

Проверка скачанного файла на Windows: `Get-FileHash .\nuclear-stenographer-1.2.3-runtime-preview-arm64-x86_64.apk -Algorithm SHA256`. Ожидаемая сумма:
`28487befa57bae896c252ea30b8082a2bf11ae732799fb44b5ef7a3b43487af7`.

## Основной сценарий

1. Дождитесь подготовки моделей. Нажмите «Выбрать файл» и выберите WAV PCM16 или M4A/AAC.
2. Нажмите «Расшифровать». Выполняются подготовка, определение участников и распознавание.
3. После ASR сразу доступны текст, таймкоды, плеер и экспорт. Резюме локальной LLM продолжается отдельно в том же процессе.
4. Нажатие на таймкод запускает нужный участок. Плеер стенограммы поддерживает паузу, ±15 с, позицию на дорожке и 0.75/1/1.25/1.5/2×.
5. Имена участников меняются через значок редактирования. JSON сохраняет исходные ID. Резюме сверяйте со стенограммой.
6. «Экспорт» открывает TXT, JSON и просмотр JSON. В системном диалоге выберите доступный способ сохранения/передачи. Проверка внешней доставки файла не проводилась.
7. Результаты автоматически сохраняются в истории и доступны после перезапуска.

## Диктофон и аудиотека

«Записать» → «Начать запись» → при необходимости «Пауза» / «Продолжить» → «Завершить». Разрешите микрофон, задайте название, прослушайте и нажмите «Сохранить аудио» или «Расшифровать». Сохранённая запись находится в приватной аудиотеке приложения. Это не сохранение копии в Downloads. Компактный плеер аудиотеки поддерживает play/pause; скорость и перемотка доступны на экране стенограммы.

Отмена обработки кооперативная: дождитесь текущего блока. Отмена или ошибка резюме не удаляет готовый текст. Не закрывайте процесс Android во время вычислений: отдельного foreground service нет.

## Сборка исходников

См. `app/README.md` и `docs/model-bundle.md` в исходниках: Node/npm, JDK из Android Studio, SDK/NDK/CMake, `npm ci`, `npm run models:android`, Expo prebuild, Gradle assembleRelease. Веса не лежат в Git; разработчик скачивает их подготовительным скриптом с SHA-256. В проверочном APK они уже встроены.
