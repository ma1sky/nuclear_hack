## Честные границы проверки

Первый UI-прогон финального APK до восстановления эмулятора был заблокирован UiAutomation/ADB. После восстановления распознавание и перечисленные сценарии повторены успешно. При тестировании активного плеера использованы координаты кнопки из свежего статичного UI и сравнение времени до/после паузы: стандартный dump не дожидается idle при работающем таймере. Один повтор восстановления имени через кириллицу сломался в `adb input text`; повтор с ASCII успешен, это не ошибка приложения.

Нет чистой установки на Redmi, ручного эталона естественного подкаста, часового TitaNet-прогона, реального микрофона и внешнего получателя экспорта. Скорость и seek в компактном плеере аудиотеки отсутствуют.
