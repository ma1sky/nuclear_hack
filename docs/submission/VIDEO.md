# Видеодемонстрация

MP4 создаётся **Remotion 4.0.541**, исходники в `tools/demo-video/`. В основе — реальные скриншоты и screenrecord Android-эмулятора с APK 1.2.3 (SHA-256 в README). Это монтаж демонстрации: статичные экраны, подписи и ускоренные переходы; не замер времени ASR. Звуковая дорожка не требуется для чтения русских подписей и не используется как доказательство качества распознавания.

Показываются аудиотека, выбор файла WAV/M4A, обработка, стенограмма с участниками и таймкодами, ранний показ текста, локальное резюме, play/pause, перемотка, скорость, JSON/TXT, история, запись, пауза/продолжение, сохранение и повторное открытие аудио. Подписи ограничений включены в финал.

Для повторного рендера: `cd tools/demo-video`, `npm ci`, `npm run render`. Требуется Chrome по указанному в package.json пути либо замена `--browser-executable`. Экранные материалы в public входят в исходный архив; большие промежуточные записи и MP4 не хранятся в обычном Git. Ссылка на готовое видео — в корневом README.

Справка CLI: https://www.remotion.dev/docs/cli/render .
