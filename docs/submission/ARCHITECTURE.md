# Архитектура и модели

UI: React Native 0.88, TypeScript, Expo SDK 58, Expo Router. Нативный модуль `audio-engine` на Kotlin. Инференс CPU: sherpa-onnx 2.0.1 и llama.rn 0.12.9. Интерфейс соответствует текущей светлой версии макета Figma.

## Конвейер

Файл → MediaExtractor/MediaCodec или RIFF PCM16 → mono 16 kHz в PCM на диске → диаризация окнами до 120 с → совместное сопоставление голосов между окнами → освобождение диаризатора → GigaAM блоками до 20 с → сохранение стенограммы/доступный экспорт → освобождение ASR → Qwen → отдельное сохранение резюме.

Все модели поставляются внутри APK, проверяются по SHA-256 и копируются в приватный каталог. Одновременно работает одна задача. Диаризатор и дополнительный extractor переиспользуются между окнами. Информация о результате сохраняется до LLM; резюме не меняет эталонный JSON.

| Роль | Модель |
|---|---|
| Русская речь | GigaAM v2 CTC INT8: gigaam-v2.int8.onnx + gigaam-tokens.txt |
| Сегментация | pyannote segmentation 3.0 INT8 |
| Признаки голоса | NVIDIA NeMo TitaNet-Small: nemo_en_titanet_small.onnx |
| Резюме | Qwen2.5-0.5B-Instruct GGUF Q4_K_M |

Последовательная загрузка снижает одновременную память моделей. Аудио не загружается целиком в Java-кучу. Нативная память моделей при этом остаётся существенной. Диаризация — 2 потока; ASR — 4 на x86_64 с минимум 4 CPU, на ARM — 2; Qwen — 2 потока, контекст 2048, ответ до 160 токенов, temperature 0.

Сопоставление: нормализованные embeddings, локальное объединение непересекающихся фрагментов и взаимно-однозначное назначение между окнами. При недостаточных признаках используется speaker_unknown. Количество участников автоматическое, номера назначаются по первому появлению в записи.

## Данные

Приватные файлы истории и аудиотеки. JSON для оценки строго имеет вид:

```json
{"transcript":[{"speaker_id":"speaker_1","start_ms":0,"end_ms":1000,"text":"Пример"}]}
```

Метки — целые миллисекунды исходной записи. Имена, резюме и метрики хранятся отдельно. TXT — человекочитаемый протокол, может содержать имена и резюме.

Источники, лицензии и SHA-256: `docs/model-bundle.md`, `docs/licenses/titanet-small.txt` и `artifacts/test-results/runtime-options-2026-11-08/release-verification.json`. Подробные параметры: `docs/stack.md` и `docs/runtime-options-2026-11-08.md`.
