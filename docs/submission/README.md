# Комплект сдачи

Семь материалов и прямые ссылки собраны в корневом `README.md` в разделе «Материалы сдачи».

1. APK 1.2.3 ARM64/x86_64, все модели внутри.
2. Архив исходного кода + Git-репозиторий; веса скачиваются подготовительным скриптом, APK содержит их.
3. INSTALL.md — установка, использование, сборка.
4. ARCHITECTURE.md — конвейер и модели.
5. LIMITATIONS.md — фактические ограничения.
6. TESTS.md — собственные тесты и ссылки на агрегаты.
7. VIDEO.md + demo-real.mp4 — полноценные сквозные сценарии через Remotion, исходники композиции приложены.

APK и видео — GitHub Release assets; документация и код — Git. Организаторы должны иметь доступ к закрытому репозиторию либо получить файлы через площадку сдачи. Автоматической отправки на внешнюю площадку хакатона не выполнялось: её адрес не указан.
