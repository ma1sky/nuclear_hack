## Изменения

- Светлые нейтральные токены Figma, Inter, карточки с отступом 12,
  общие отступы 16/24, кнопки и области нажатия 48 dp.
- Аудиотека: компактные записи, последние две расшифровки, отдельные страницы
  «Все записи» и «Все расшифровки». В заполненной аудиотеке убрана иконка истории
  из шапки: история открывается через «Все».
- Воспроизведение записи доступно непосредственно по кнопке Play; название
  открывает остановленный плеер. Меню записи открывается поверх текущего списка:
  прослушать, расшифровать, переименовать, удалить, закрыть.
- Переименование записи — общий диалог с полем и горизонтальными кнопками.
- Вкладки результата высотой 48, выбранная область 40; компактные этапы обработки.
  Участники доступны и из реплик, и из резюме.
- Нижний плеер: временная шкала, скорость, ±15 секунд, Play/Pause, экспорт.
  Нажатия на дочерние полосы волны не искажают позицию перемотки.
- Экспорт — диалог поверх результата; возврат из JSON возвращает именно к экспорту.
  В JSON показаны реальные данные и обязательные поля transcript/speaker_id/
  start_ms/end_ms/text. Неправильный демонстрационный segments из Figma не перенесён.
- Диктофон сохранён; пояснение о разрешении микрофона убрано из обычного экрана.
  Реальный запрос разрешения и состояние отказа остались.

Использованы существующие React Native Reusables и локальные SVG Figma.
Временные URL Figma не используются в приложении. Зависимости, модели,
сервисы обработки и Kotlin-аудиодвижок не изменены. Удаление расшифровки сохранено
дополнительным действием её меню, чтобы обновление UI не убирало прежнюю функцию.
Системная строка состояния Android остаётся настоящей; демонстрационные часы
и статические волны из макета не имитируются.

## Запуск на этом ПК

Ярлык «Нейро-стенографист — эмулятор» на рабочем столе запускает Release12
и team.hex.nuclearstenographer. Повторный запуск использует существующий AVD.
Скрипты: tools/windows-build/Start-Stenographer.ps1 и Install-DesktopShortcut.ps1.
Не очищает данные, не требует Metro; если приложения нет, устанавливает локальный APK.
