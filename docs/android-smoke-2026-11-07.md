## Исправления окружения сборки

Установлены недостающие официальные Android NDK **27.1.12297006**, Build Tools **37.0.0**, CMake **3.22.1**. Архивы сверены по размеру и SHA-1 из официального `repository2-3.xml`.

На Windows Ninja выдавал `Filename longer than 260 characters` при компиляции codegen safe-area-context. В проект добавлен воспроизводимый Expo config plugin `app/plugins/withShortNativePaths.cjs`: `CMAKE_OBJECT_PATH_MAX=240`. Системные настройки Windows не менялись.

Для нестабильных TLS-загрузок Maven использован временный локальный кэш, получавший зависимости через curl с проверкой сертификатов с официальных Google Maven, Maven Central и Gradle Plugin Portal. Для сборки подпроектов Android Gradle Plugin согласован с корневым **9.2.1** через локальный init script; код node_modules не редактировался. Это обход проблемы окружения конкретного ПК, а не требование для работы APK. На другом ПК при воспроизведении могут потребоваться собственная сетевая настройка и установка SDK.
